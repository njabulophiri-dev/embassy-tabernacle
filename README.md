# Embassy Tabernacle Church Website

A three-page Next.js and Tailwind CSS website for Embassy Tabernacle Church.

## Pages

- Home: `/`
- About Us: `/about-us`
- Sermons: `/sermons`

The Giving, Contact, media, podcast, and Plan Your Visit links are placeholders for later integration.

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
